# Honeycomb

Use the shared meanings in [DICTIONARY.md](DICTIONARY.md).

Honeycomb turns ideas into shipped software through specialized agents, verification, and human judgment. Skills pass work through YAML; adapters provide project-specific operations.

Idea → Validate → Define → Plan → Implement → QA → Human review → Ship.

[setup](SETUP.md)

## Shared operations

For “publish the implementation and evidence,” use the workspace adapter to commit and make the deliverables accessible, and the tracker adapter to link them from the node.

For “complete the node,” use the tracker adapter to mark it complete once its goals and verification are satisfied and its deliverables are published.
