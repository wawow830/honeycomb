| Term | Meaning |
|---|---|
| Production | One effort taking a human idea through to delivery. |
| Pass | One iteration toward an approved result. |
| Node | A bounded, independently verifiable assignment in a plan. |
| Frontier | Unclaimed nodes whose dependencies are satisfied. |
| Verification | Executable checks of specified behavior or constraints. |
| Evidence | Observations, artifacts, or reasoning supporting a claim. |
| Finding | A substantiated shortcoming in the implementation or result. |
| Approval | A human decision accepting a specific artifact or result. |
